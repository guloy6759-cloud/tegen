# TEGEN

Telegram Mini App va bot asosidagi onlayn do‘kon.

## Tuzilishi

- `apps/bot` — Telegram bot
- `apps/mini-app` — Telegram Mini App
- `server` — Backend API
- `server/prisma` — PostgreSQL ma'lumotlar bazasi sxemasi

## Ishga tushirish

npm install

### Bot

npm --workspace apps/bot start

### Mini App

npm run dev:web

### API

npm run dev:api
